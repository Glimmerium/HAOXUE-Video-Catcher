# 好学视频合并工具

将北大好学 APP 已下载的分片视频导出并合成为完整 MP4，支持 Windows 图形界面和 BlueStacks 自动导入。

## 项目背景

有些课程回放在教学网上找不到，却仍能在“好学”APP 中查看并下载。但APP内的下载只是使其可以离线播放，并没有办法对视频本身进行其他编辑操作。为了方便复习整理，需要将课程下载从“好学”APP中提取出来，并（由于最新的教学网课程加密）解密整理成完整视频。

iOS 的应用文件访问限制使直接导出不方便；安卓端虽然可以通过模拟器访问下载文件，但手动寻找目录、显示以点开头的隐藏文件夹、配对清单与密钥，再打包传到 Windows、解压和合并，步骤繁琐且容易出错。

本项目把下载之后的提取与合并集中到一个界面：在好学 APP 中下载完成后，选择视频即可自动复制所需文件并生成 MP4，省去 Root Explorer、ZIP 中转和手动整理的时间。

## 功能

- **模拟器导入**：通过 BlueStacks 自带的 ADB 扫描好学默认下载目录，列出视频时长、分片数和文件标识。
- **自动提取与合并**：读取 M3U8 引用，复制密钥及分片，解密 AES-128 HLS 并通过 FFmpeg 合并为 MP4，不重新编码。
- **本地文件夹导入**：支持已经导出的 M3U8、密钥及分片目录，修正清单中的安卓旧路径。
- **输出管理**：默认保存到当前用户桌面，可修改目录；模拟器导入时可自定义文件名，同名自动编号。
- **进度与取消**：复制阶段显示活动进度，合并阶段显示百分比；详细合并日志通过“查看日志”打开。
- **保留原文件**：不会删除或修改模拟器中的课程文件；导入使用的临时副本自动清理。
- **作者信息**：点击右上角个人 logo 查看作者提示。

## 使用方法

### 从 BlueStacks 导入

1. 安装并启动 BlueStacks，在模拟器中安装北大好学 APP，登录自己的账号。
2. 在 BlueStacks 的“设置 → 高级”开启 **Android 调试桥（ADB）** 并保存，必要时重启。
3. 在好学 APP 内完成视频下载，保持模拟器运行。
4. 启动本工具，设置保存目录，点击 **从 BlueStacks 导入…**。
5. 选择视频、填写输出名称，点击 **导入并合并**。

无需 Root Explorer、手动压缩或解压。列表目前不显示真实课程名，可根据时长和文件标识区分视频；每次处理一个视频。

### 从本地文件夹导入

将一个 `.m3u8` 清单、其引用的 `.key` 密钥和分片文件夹放在同一目录，保留原始名称。在主窗口选择“视频源文件夹”，点击“开始合并”。

## 从源码运行

环境：Windows、带 Tkinter 的 Python 3.9 或更高版本。模拟器导入还需要本机安装 BlueStacks 并开启 ADB。

```powershell
python -m pip install -r requirements.txt
python video_merge_gui.py
```

命令行方式：

```powershell
python decrypt_merge.py --playlist "下载目录\video.m3u8" --output "完整视频.mp4"
```

FFmpeg 可以来自系统 PATH，或 `imageio-ffmpeg` 提供的本地程序。命令行也支持 `--ffmpeg` 指定路径。

## 打包 Windows EXE

在 Windows 上运行：

```powershell
python -m pip install -r requirements-build.txt
python build_exe.py
```

输出为 `dist/VideoMerge.exe`，包含 logo 和 FFmpeg。用户使用 EXE 无需另装 Python。打包工具会生成本地 `build/`、`dist/` 和 `.spec` 文件，均不应提交到源码仓库。

本项目不附带 BlueStacks 安装器、好学 APK、课程视频或密钥；请自行从相应官方或校内渠道获取应用。

## 限制与排错

- 已在 BlueStacks 5 中国版环境验证，其他版本或存储结构不保证兼容。
- 未连接到模拟器时，检查模拟器是否运行、ADB 是否开启。
- 默认读取 `/storage/emulated/0/Android/data/com.pku.studious/files/Video/Download`。
- 清单结束标记和分片存在检查不能完全替代 APP 的下载完成状态，请先在 APP 中确认。
- 导入和合并期间需要容纳分片副本与 MP4，建议预留至少下载体积两倍的空间并留有余量。
- 进度 99% 时可能正在整理 MP4；源文件若损坏，仍可能出现花屏或音画异常。
- 这是本地下载文件整理工具，不负责登录、获取课程权限或从APP里自动下载课程。
